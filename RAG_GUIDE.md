# RAG — AI Project Manager Assistant

Актуальная инструкция и команды: [README](README.md).

База: `data/documents/1. Кодекс по реализации ИТ-проектов.docx`,
`2. Порядок ведения ИТ-проектов.docx`, `3. Инструкция РП по работе в ИСУП.docx`.
Демонстрационные TXT не используются. Чтение DOCX: обычные абзацы по порядку,
затем существующий splitter → OpenAI embeddings → Chroma → retrieval → LLM.

После настройки `.env`: `python main.py`, `/index`, `/stats`, `/mode rag`.
`/index` перестраивает прежнюю коллекцию и использует API. Перезапуск сам
не индексирует документы. Имена источников сохраняются в метаданных.
